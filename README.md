# Bluetooth Device Scanner - Android App

[![Platform](https://img.shields.io/badge/Platform-Android-green.svg)](https://www.android.com/)
[![API](https://img.shields.io/badge/API-21%2B-brightgreen.svg)](https://developer.android.com/about/dashboards)

A modern Android application for discovering nearby Bluetooth devices with detailed device information and signal strength analysis.

<img src="screenshots/scanning.png" width="200" alt="Scanning Screenshot"> <img src="screenshots/results.png" width="200" alt="Results Screenshot">

## Features

- **Bluetooth LE Device Discovery**
- Device Type Detection (Smartphone, Headphones, Wearables, etc.)
- Signal Strength (RSSI) Visualization with Color Coding
- MAC Address Display
- Modern Android Permissions Handling
- Material Design Interface
- Support for Android 5.0+ (API 21 and higher)

## Requirements

- Android device with Bluetooth 4.0+
- Android SDK 33+
- Gradle 8.0+
